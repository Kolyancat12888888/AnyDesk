# AnyDesk Session & Incident Inspector (Forensics + Alerting)

Утилита на C# (.NET 8) для форензик-анализа, аудита входящих подключений AnyDesk, определения геолокации/провайдеров и формирования доказательной базы при расследовании инцидентов удаленного доступа / компьютерного мошенничества.

---

## 🚀 Основные возможности

1. **🔒 Сохранность цифровых улик (Chain of Custody)**:
   - Автоматический поиск лог-файлов AnyDesk (`ad.trace`, `ad_svc.trace`, `connection_trace.txt`, `*.conf`).
   - Расчет криптографических хэшей **SHA-256** для фиксации неизменности логов.

2. **⏱️ Криминалистический таймлайн событий**:
   - Построение хронологии входящих сессий, попыток входа, запросов авторизации и идентификаторов AnyDesk User ID.

3. **📡 Мониторинг сети в реальном времени (Win32 API)**:
   - Анализ активных TCP-сокетов процесса `AnyDesk.exe` через `GetExtendedTcpTable` (`iphlpapi.dll`).

4. **🗺️ Интерактивная карта и GeoIP**:
   - Определение страны, региона, города, провайдера (ISP), AS/организации и координат.
   - Встроенная интерактивная карта **OpenStreetMap (Leaflet)** в HTML-отчете.

5. **📄 Генератор заявления в МВД / Службу безопасности банка**:
   - Автоматическое создание предзаполненного текста заявления (`Police_Statement_*.txt`) с датами, внешними IP, провайдерами и SHA-256 хэшами.

6. **📱 Экстренные Telegram-уведомления**:
   - Мгновенная отправка алертов о подключении в указанный Telegram-чат/канал.

7. **💾 Экспорт данных**:
   - `Forensic_Report_*.html` (Интерактивный отчет с картой и таблицами).
   - `Police_Statement_*.txt` (Официальный бланк заявления).
   - `Forensic_Data_*.json` (Структурированные данные для SIEM/экспертизы).

## 🛠️ Сборка и запуск

### Требования
* [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)

### Запуск из исходников
```bash
# Стандартный запуск с открытием отчета
dotnet run

# Запуск в тихом режиме с отправкой тревоги в Telegram
dotnet run -- --silent --telegram
```

### Сборка единого .exe файла (Self-contained)
```bash
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```
